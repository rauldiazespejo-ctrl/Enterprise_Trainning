## 2025-03-03 - Accessible Icon-Only Data Table Actions
**Learning:** Icon-only action buttons in internal data tables (like the Super Admin user management panel) frequently lack programmatic accessible names and rely only on visual tooltips (`title`). This severely impacts screen reader users trying to manage data records. Additionally, inline input adornment buttons (like show/hide password toggles) can lack keyboard focus styling (`focus-ring`).
**Action:** When auditing data tables or complex forms, verify that every icon-only button contains a descriptive `aria-label` that includes context (e.g., `aria-label={"Promover a " + u.name + " a Admin"}`), applies `focus-ring` classes for visible keyboard focus, and sets `aria-hidden="true"` on the enclosed `lucide-react` icons.
