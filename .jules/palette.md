## 2024-05-15 - Pagination Accessibility
**Learning:** Pagination controls in React require specific ARIA attributes to be fully accessible, including `aria-live="polite"` and `aria-atomic="true"` on the summary text, a structural `<nav>` wrapper with a descriptive label (e.g., `aria-label="Navegación de páginas"`), `aria-current="page"` on the active page button, and `aria-hidden="true"` on decorative ellipsis indicators. These ensure correct screen reader announcements for complex dynamic data elements.
**Action:** When implementing or refactoring pagination or dynamically updated lists, always wrap the interactive elements in a semantic `<nav>` with a context-appropriate label, ensure state changes (like 'Showing X of Y') are announced using polite live regions, and hide non-interactive decorative elements from assistive technologies.
