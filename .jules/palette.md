## 2026-08-18 - Pagination Accessibility
**Learning:** Proper pagination a11y requires semantic nav, aria-live for summary, active state indicators (aria-current), and hiding decorative elements (aria-hidden).
**Action:** Always use nav with aria-label, update dynamic summaries with aria-live="polite", use aria-current="page" for active item, and hide icons/ellipses with aria-hidden="true".
