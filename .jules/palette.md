## 2025-01-20 - Pagination Accessibility and Semantics
**Learning:** Decorative text elements in pagination (like ellipses `...`) can create noise for screen reader users if not explicitly hidden. Standard generic container elements for pagination controls do not provide enough context for assistive technologies without proper semantic landmarks (`<nav>`) and ARIA labels. Dynamic list summaries ("Showing 1-10 of 50") must use live regions (`aria-live="polite"`) to notify users of content changes when paginating.
**Action:** When implementing pagination or similar structural visual elements, always wrap the container in a semantic `<nav>` element with an appropriate `aria-label`. Ensure decorative non-interactive elements have `aria-hidden="true"`. Apply `aria-live="polite"` and `aria-atomic="true"` to summary information elements to ensure changes are announced. Always use `aria-label` and `aria-current="page"` for active page buttons.
