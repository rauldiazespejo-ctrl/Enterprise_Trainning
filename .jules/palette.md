## 2024-03-05 - Accessible Pagination Update
**Learning:** Replaced the default `div` container in the Pagination component with a semantic `nav` wrapper containing an `aria-label`. Individual page buttons now correctly use `aria-current="page"` and `aria-label`, and the decorative ellipsis span is hidden from screen readers with `aria-hidden="true"`. Applied project-specific `.focus-ring` and `.tap-target-min` CSS classes to navigation elements.
**Action:** Always wrap pagination controls in a `<nav>` element with a descriptive `aria-label`. Apply `aria-current="page"` to the active page button and individual `aria-label`s to each page number button. Use `aria-hidden="true"` on decorative elements like ellipses to prevent confusing screen reader announcements. Use project-specific `.focus-ring` and `.tap-target-min` utility classes on interactive elements to enforce accessibility standards.
