## 2026-08-25 - Component Localization Requirements
**Learning:** The application heavily utilizes Spanish localization for screen reader text. It's critical that all ARIA labels and contextual announcements match this localization scheme.
**Action:** Always ensure ARIA text (e.g., `aria-label="Navegación de páginas"`, `aria-label=Página X`) uses idiomatic Spanish when modifying components in this project.
