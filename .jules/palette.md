## 2026-09-21 - Accessible Pagination Component
**Learning:** When building pagination components, wrapping the pagination controls in a semantic `<nav>` element with a descriptive `aria-label` (e.g., `aria-label="Navegación de páginas"`) provides necessary structural context for assistive technologies. Additionally, hiding decorative or purely structural text elements (like an ellipsis `<span>`) from screen readers by applying the `aria-hidden="true"` attribute prevents confusing announcements. Ensure the button representing the currently active page includes the `aria-current="page"` attribute so its state is properly communicated to assistive technologies.
**Action:** Always wrap pagination controls in a `<nav>` element with an `aria-label`, use `aria-current="page"` for active pages, and apply `aria-hidden="true"` to visual separators like ellipses to ensure full keyboard and screen reader accessibility.
