## 2023-10-27 - Pagination Accessibility Standards
**Learning:** Reusable navigation components like `Pagination.tsx` often lack critical structural context for screen readers if built purely with `<divs>`. Wrapping them in `<nav aria-label="...">` is required for defining navigational landmarks. Furthermore, dynamic counter updates (like "Showing 1-10 of 50") must use `aria-live="polite"` and `aria-atomic="true"`, otherwise screen reader users will not be informed of state changes when paging.
**Action:** When implementing or modifying structural pagination, always ensure: 1) the container is a semantic `<nav>` with an appropriate ARIA label, 2) active elements correctly use `aria-current="page"`, 3) dynamic summaries use polite `aria-live` regions, and 4) decorative icons/ellipses are explicitly hidden via `aria-hidden="true"`.
