## 2024-11-06 - [Fix IDOR vulnerability in Edge Function JWT parsing]
**Vulnerability:** The `audit-log` edge function had an Insecure Direct Object Reference (IDOR) vulnerability. It relied on the `user_id` passed via the client request body rather than securely resolving it from the JWT in the `Authorization` header. A malicious user could forge audit logs on behalf of other users or spoof actions.
**Learning:** Edge Functions in Supabase must inherently enforce validation of JWT tokens and not trust any `user_id` inside body requests for non-exempt events. The client SDK may automatically insert `Authorization` headers but it requires the Edge Function code to correctly reconstruct the user object to ascertain their true identity.
**Prevention:** Always extract the user context via `authClient.auth.getUser()` securely on the server-side, by initialising the Supabase client using the `Authorization` header directly. Implement a fail-closed mechanism to reject any unauthorized access missing valid headers. Exempt specific actions (like logins or password resets where a valid JWT might genuinely be absent) utilizing secure fallbacks.
