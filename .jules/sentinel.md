## 2024-10-31 - Fix SSRF via DNS Rebinding in scrape-url
**Vulnerability:** Server-Side Request Forgery (SSRF) and potential DNS Rebinding vulnerability in Deno/Supabase Edge Function (`scrape-url`). User-supplied URLs were fetched directly without network boundary validation.
**Learning:** `fetch` follows redirects by default and evaluates DNS at fetch time. To protect internal services, DNS resolution (`Deno.resolveDns`) must happen prior to fetch per hop to validate IPs, and `fetch` must be set to `redirect: 'manual'` with manual redirect handling and response stream cancellation (`response.body?.cancel()`) to prevent resource leaks when dropping a response body.
**Prevention:** Implement an IP boundary check mapping for internal/private subnets (`isLocalOrPrivateIp`). When resolving hostnames, test both IPv4 and IPv6 (`A` and `AAAA` records) to enforce boundaries safely, strictly handle redirect loops within limits, and always clear network streams if the body is ignored.
