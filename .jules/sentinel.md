## 2024-03-24 - IDOR Vulnerability in Audit Log Edge Function
**Vulnerability:** The `audit-log` edge function in Supabase accepted a `user_id` field in the JSON request body and blindly used it to record the audit log entry using a bypass RLS `service_role` admin client, allowing any user to spoof audit logs for any other user (IDOR).
**Learning:** Supabase Edge Functions often use the `SUPABASE_SERVICE_ROLE_KEY` to bypass Row Level Security (RLS) for internal operations. When using this key, the `Authorization` header is not implicitly verified or trusted.
**Prevention:** Never trust user IDs or sensitive data provided in the request body for authentication or auditing when using `service_role` keys. Always explicitly enforce authentication by creating a client with `SUPABASE_ANON_KEY` and the `Authorization` header, and retrieve the user securely via `supabase.auth.getUser()`, overwriting the provided user ID. Allow explicit bypasses only for unauthenticated actions (like login/signup) where falling back to the body's ID is intended.
