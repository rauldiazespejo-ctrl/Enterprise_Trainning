## 2024-05-24 - [Supabase Edge Functions SSRF and DNS Rebinding]
**Vulnerability:** Found a Server-Side Request Forgery (SSRF) vulnerability in `supabase/functions/scrape-url/index.ts` where user-provided URLs were fetched without validation against private IP ranges or local hostnames.
**Learning:** Supabase Edge Functions (Deno) do not automatically block outbound requests to internal or private networks when using the standard `fetch` API. Validating IPs via `Deno.resolveDns()` and then fetching the original hostname leaves a Time-of-Check to Time-of-Use (TOCTOU) vulnerability (DNS rebinding). Conversely, replacing the hostname with the resolved IP in the `fetch` URL breaks HTTPS Server Name Indication (SNI). Robust DNS rebinding protection with standard `fetch` requires specialized proxying or HTTP clients that support custom SNI injection alongside pinned IPs.
**Prevention:** Always implement explicit URL validation before using `fetch` in edge functions. Parse the URL with `new URL()`, ensure the protocol is HTTP/HTTPS, and explicitly block local, private, internal, and cloud metadata IP addresses and hostnames. Acknowledge and document the TOCTOU limitation if relying on `Deno.resolveDns` for pre-resolution checks without custom proxies.
