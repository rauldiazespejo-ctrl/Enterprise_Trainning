## 2025-02-14 - IDOR Vulnerability in Audit Log Edge Function
**Vulnerability:** The `audit-log` edge function was vulnerable to Insecure Direct Object References (IDOR). It blindly trusted the `user_id` provided in the request body, allowing an attacker to submit audit logs pretending to be any user.
**Learning:** This vulnerability existed because the edge function relied on the request body for identity rather than authenticating the caller. While the edge function correctly used the service role key to bypass RLS for inserting the log entry, it failed to verify the identity of the user making the request.
**Prevention:** Always implement a fail-closed mechanism when extracting identity. Instead of trusting the request body, create a dedicated `callerClient` using `createClient` with the `SUPABASE_ANON_KEY` and the caller's `Authorization` header to verify the JWT and extract the `user_id` securely. Explicitly throw an 'Unauthorized' error if the auth header is missing or `getUser()` fails for non-exempt actions.
