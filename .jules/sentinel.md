## 2024-05-15 - SSRF Vulnerability in Scrape-URL Function
**Vulnerability:** The `scrape-url` Supabase Edge Function directly fetched user-provided URLs without validating the protocol, hostname, or resolved IPs. This allowed an attacker to request internal network resources (like 127.0.0.1, AWS metadata, etc.).
**Learning:** Using `fetch(url)` in Edge Functions where the URL comes from user input is dangerous because Edge Functions may have access to internal network interfaces or metadata services not accessible from the public internet. DNS rebinding and HTTP redirects can bypass naive hostname checks.
**Prevention:** Implement strict SSRF validation for user-provided URLs: 1) Validate URL scheme (`http`/`https`). 2) Block private/local IP ranges and hostnames. 3) Use `Deno.resolveDns` to resolve the hostname and verify the resulting IPs aren't private (mitigates DNS rebinding). 4) Use `{ redirect: 'manual' }` in `fetch` and manually validate redirect `Location` URLs.
