## 2024-05-24 - SSRF in scrape-url Edge Function
**Vulnerability:** The Deno/Supabase `scrape-url` Edge Function was blindly fetching any user-provided URL (`fetch(url)`). This allowed a Server-Side Request Forgery (SSRF) attack where an attacker could provide URLs resolving to internal/private IPs (like `169.254.169.254` for AWS metadata, or `127.0.0.1`), effectively using the edge function as a proxy into the internal network.
**Learning:** When using `fetch()` with user-provided URLs in backend functions, the browser/runtime will automatically follow redirects and make requests without restricting destination IPs. The naive approach fails to validate that the host resolves to a public, external IP.
**Prevention:** Strictly implement SSRF protection by setting `{ redirect: 'manual' }` in the `fetch` options, manually handling all redirects, applying DNS resolution checks (using `Deno.resolveDns` for both 'A' and 'AAAA' records) on every hop to block internal/private IPs, and cancelling discarded responses (`response.body.cancel()`) to prevent resource leaks.
