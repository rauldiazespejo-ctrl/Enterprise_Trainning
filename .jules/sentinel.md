## 2025-03-09 - Missing Authentication on Expensive Edge Functions
**Vulnerability:** The `generate-course` Supabase Edge Function lacked explicit authentication validation via `supabase.auth.getUser()`.
**Learning:** Supabase Edge Functions do not enforce authentication by default. Developers must manually extract the `Authorization` header and initialize an isolated Supabase client to validate the token. Since this specific function interacts with a paid third-party AI API (DeepSeek), leaving it unauthenticated exposes the application to potentially significant financial drain if the endpoint is discovered and abused by malicious actors.
**Prevention:** Always follow the "Fail Closed" principle on Edge Functions that interact with paid APIs or sensitive data. Explicitly validate the request's `Authorization` header using `supabase.auth.getUser()` and throw an error if the token or environment configuration is missing, ensuring access is strictly denied by default.
