## 2024-08-18 - Missing Authentication in Supabase Edge Functions
**Vulnerability:** The `audit-log` and `generate-course` Supabase Edge functions do not verify if the request comes from an authenticated user before executing actions (inserting audit logs or generating course content with the DeepSeek API). The `audit-log` function only expects a `user_id` in the body but doesn't validate it securely, enabling log spoofing. The `generate-course` function calls an external AI API with an API key, allowing unauthenticated users to exhaust rate limits or use up API credits.
**Learning:** In Supabase, Edge Functions deployed without specific JWT verification configurations or explicit `supabase.auth.getUser()` checks allow anyone to call them as long as CORS permits it (which can be bypassed by non-browser clients).
**Prevention:** Always require an `Authorization` header and validate it using `callerClient.auth.getUser()` within Edge Functions that perform sensitive operations or call external APIs.
