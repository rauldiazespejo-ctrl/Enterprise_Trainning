## 2025-02-14 - Fix IDOR in audit-log edge function
**Vulnerability:** The `audit-log` edge function relies on `user_id` provided in the request body to log events. Since it uses `SUPABASE_SERVICE_ROLE_KEY` to insert into the database, it bypasses RLS and allows any user to spoof the `user_id` of other users.
**Learning:** In Supabase Edge Functions, using the service role key bypasses Row Level Security. When accepting user-provided data for logging (or any sensitive action), you must manually verify the user's identity via the `Authorization` header instead of trusting the request body payload. However, certain unauthenticated actions like `login`, `login_failed`, `logout`, and `signup` still need to be logged with the provided `user_id`.
**Prevention:** Always authenticate the user using `supabase.auth.getUser()` with the `Authorization` header in edge functions that use the service role key. Overwrite any user-provided `user_id` with the authenticated `user.id`. Explicitly define and handle unauthenticated actions if necessary.
