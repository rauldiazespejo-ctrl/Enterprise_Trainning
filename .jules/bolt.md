## 2024-03-24 - O(N*M) Abstraction Leaks and Optimal Maps
**Learning:** When attempting to optimize global O(N*M) array iterations within React (such as inside a `.map` to fetch related context state), it's easy to inadvertently bypass encapsulating helper methods, raising reviewer flags about abstraction leaks. Replacing direct `.find()` searches within an iterative process with O(1) `Map` lookups inside a `useMemo` preserves encapsulation while vastly improving time complexity (to O(N+M)).
**Action:** When optimizing performance in lists or aggregate functions, always build frequency or lookup maps via `useMemo` for the raw arrays rather than looping over them. This prevents unneeded recalculations and avoids N+1 / N*M complexity on re-renders, particularly when dealing with search filtering logic that runs frequently as the user types.
