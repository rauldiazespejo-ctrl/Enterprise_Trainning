## 2024-10-01 - Optimizing Aggregations in React Components
**Learning:** When calculating global aggregate stats (like `totalCompleted`) in React components that also render paginated list views, moving expensive O(N*M) helper function calls (like `employeeStats`) inside a `reduce` block without memoizing the inputs still triggers full recalculation on every render (e.g., when a search term changes). However, extracting the nested helper calls into a flat O(1) lookup map (like `certificateCounts`) and memoizing the global aggregation independently of the list rendering provides a massive performance boost without breaking encapsulation.
**Action:** Always memoize derived aggregation state using `useMemo` and replace nested `.filter()` iterations with pre-calculated O(1) `Map` lookups inside the memoization block.
