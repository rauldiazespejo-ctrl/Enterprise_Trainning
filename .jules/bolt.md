## 2025-03-09 - Optimize React O(N*M) Context Helper Lookups
**Learning:** In React, utilizing context helper functions that perform O(N) array filtering (e.g. `getUserAssignments(userId)`) inside `.map()` or `.reduce()` loops creates a synchronous O(N*M) bottleneck during rendering. This blocks the main thread, especially problematic when rendering lists dynamically filtering on user input (like search bars).
**Action:** Bypass these O(N) context helpers by pulling the raw context arrays into the component and using a single `useMemo` hook to iterate over them *once*, constructing a grouped O(1) Map. Retrieve values directly from this Map during the render loop to achieve optimal rendering performance. Always define fallback objects for Map lookups outside the component (or memoize them) to maintain referential equality.
