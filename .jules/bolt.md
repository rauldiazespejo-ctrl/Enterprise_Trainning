## 2024-05-24 - Optimization of derived statistics in EmployeeManagement.tsx
**Learning:** In list/management React components (like admin panels), aggressively wrap derived data calculations (e.g., filtered arrays, aggregated stats) in `useMemo` to prevent expensive O(N) or O(N^2) recalculations from triggering on frequent state updates, such as search input keystrokes. Here, the `employeeStats` method was doing O(N) array scans inside `reduce` and `filter` and then inside `.map()`, creating an O(N*M) lookup. Pre-calculating this in a `useMemo` as a `Map` changes the complexity to O(N+M) and only reruns when data changes.
**Action:** Use `useMemo` with Map creation to group the underlying arrays and achieve O(1) lookups for per-item statistics, bypassing O(N) helper functions that get called inside loops.
