## 2024-11-06 - Avoid O(N) context helpers in render loops
**Learning:** Found a severe performance anti-pattern in `src/pages/admin/EmployeeManagement.tsx`. The component used a context helper function (`getUserAssignments`) inside a loop during rendering (`employeeStats`), resulting in an O(N*M) nested loop (where N is the number of employees and M is the number of assignments). This caused severe performance degradation as the number of users and assignments grew.
**Action:** Always refactor O(N) helper function calls inside loops by pre-computing an O(1) frequency map before the loop. Use `React.useMemo` to construct the map with a single pass over the raw data arrays, drastically reducing the complexity to O(N+M). Be sure to include fallback defaults when looking up values in the map to prevent undefined reference errors, and wrap any derived helper functions in `React.useCallback`.
