
## 2024-05-18 - Avoid re-computing derived arrays and global aggregates in React loops
**Learning:** In list/management React components with pagination (like admin panels), locally derived arrays or objects (like `employees = users.filter(...)`) should be memoized. If not, they are recreated on every render. More importantly, when computing global aggregate statistics (like `totalCompleted` or `totalInTraining`), calculating them eagerly on every render for all items can cause massive performance hits if they depend on expensive context helpers (like `employeeStats` using `getUserAssignments`). By consolidating multiple passes into a single `.reduce()` and memoizing the result with `useMemo`, we prevent unnecessary O(N*M) recalculations.
**Action:** When computing derived stats for lists, use `useMemo` to cache derived arrays. Additionally, consolidate multiple O(N) array traversals (like `.filter().length` and `.reduce()`) into a single O(N) `.reduce()` pass and wrap it in `useMemo` to prevent constant re-computation on every key stroke or render. When using existing context helpers, build frequency maps (e.g. for `certificates`) using `useMemo` to achieve O(1) lookups instead of iterating raw arrays repeatedly.
