## 2026-08-13 - Optimize O(N*M) stats derivation with Map in React Component
**Learning:** In highly derived views with multiple metrics computed per user (e.g. employee metrics where N users have M assignments/certificates), calling helper functions like `getUserAssignments` per user inside loops triggers redundant O(N) array traversals (overall O(N*M) performance). It is crucial to replace inline helpers with a single-pass  computation to construct a map grouping stats directly by ID.
**Action:** Bypass these generic helpers for batch operations in list views. Instead, group flat arrays (, ) by related ID into a `Map` inside a `useMemo` block, then perform O(1) lookups and separate metric reductions on the mapped values.
