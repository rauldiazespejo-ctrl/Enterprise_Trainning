## 2024-05-24 - Memoizing Locally Derived Arrays and Pre-computing Frequency Maps for Global Aggregates
**Learning:** In list/management React components with pagination (like admin panels), calculating global aggregate statistics (like `totalCompleted`) over locally derived arrays without memoization leads to massive performance hits. If the arrays are re-created on every render and the aggregation logic relies on O(N) context helpers, the result is unnecessary O(N*M) recalculations. Bypassing context helpers entirely by iterating directly over raw arrays violates encapsulation and risks regressions.
**Action:** When computing global aggregate statistics, consolidate multiple O(N) array traversals into a single `.reduce()` pass and wrap the result in `useMemo`. Memoize locally derived arrays like `employees`. For context helpers doing O(N) filtering inside a loop, pre-compute a frequency/lookup map for the raw arrays (e.g., `certificates`) outside the loop and use that alongside the existing helpers to achieve O(1) lookups while strictly preserving encapsulation.
