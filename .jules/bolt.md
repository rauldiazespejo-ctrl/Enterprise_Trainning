## 2024-10-16 - Derived Arrays, Frequency Maps, and O(N) Reductions
**Learning:** In React components that render lists and compute aggregate statistics (like Admin dashboards), repeatedly calculating derived state without memoization leads to unnecessary O(N*M) recalculations. Relying directly on context helper functions during iteration (e.g., inside `.filter()` or `.reduce()`) exacerbates this.
**Action:** Always wrap locally derived arrays (e.g., filtered results) in `useMemo`. When optimizing around existing context helper functions that return arrays, precompute O(1) frequency or lookup maps for raw arrays instead of abandoning the helper or running nested loops. Finally, compute global aggregate statistics by consolidating multiple O(N) array traversals into a single `.reduce()` pass and wrap the result in `useMemo`.
