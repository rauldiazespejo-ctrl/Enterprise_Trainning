## 2024-10-07 - Optimize Admin Employee Management Renders
**Learning:** React component derived variables that act as lists filtering or mapping over raw arrays (e.g. `filteredEmployees` and `employees`) and unmemoized functions containing array filtration (e.g. `employeeStats`) will cause significant performance bottlenecks when recalculating on every render, especially when their output triggers dependent hooks. Similarly, calculating global aggregate stats via `reduce` within the render scope produces expensive O(N*M) recalculation during every typing stroke in a search bar (if the entire list isn't memoized).
**Action:** Always extract unmemoized arrays resulting from `.filter()` into `React.useMemo` to preserve reference equality across renders unless data has explicitly changed, and extract aggregate stat calculations operating across those arrays to prevent rendering bottlenecks. Ensure contextual mapping functions are optimized around.
