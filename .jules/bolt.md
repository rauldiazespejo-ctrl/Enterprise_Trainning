## 2023-11-20 - Memoizing Filter Pipelines and Derived State lookups
**Learning:** In list views that calculate multiple derived states on every render based on external context arrays (e.g., iterating through `assignments` and performing `.find()` on `users` and `courses` arrays), O(N*M) nested iterations can degrade performance quickly as list sizes grow, especially when reacting to keystrokes in search filters.
**Action:** Always wrap derived filtering or aggregation arrays that depend on contexts (like `users` or `courses`) in `useMemo`. Construct `Map` instances from the secondary arrays outside the iteration to convert O(M) nested lookups to O(1). Finally, consolidate `.map().filter()` chains into a single `.reduce()` pass for optimal traversal. Always explicitly cast `useMemo` dependencies (e.g., inline `filter` array references) when used within other `useMemo` hooks.
