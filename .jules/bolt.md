## 2026-10-09 - Memoization of Derived Arrays and Aggregate Stats
**Learning:** When optimizing React component performance, eagerly computing derived stats for all items upfront in a global useMemo using expensive context helpers can cause regressions, but bypassing the helper violates encapsulation. The correct approach is wrapping the existing O(N*M) aggregation logic inside a React.useMemo block to prevent recalculations on every render, while building frequency lookup maps for raw arrays and using those alongside the context helpers. Always memoize locally derived arrays to prevent dependent hooks from continuously re-executing.
**Action:** Use React.useMemo to memoize locally derived arrays used as hook dependencies, build O(1) frequency maps for raw arrays instead of bypassing context helpers, and wrap expensive global aggregations in React.useMemo blocks, consolidating them into a single .reduce() pass.
