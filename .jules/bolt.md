## 2024-11-20 - Memoizing stats over encapsulation
**Learning:** When optimizing React component performance (e.g., replacing O(N*M) loops with O(1) Maps), do not bypass or inline existing context helper functions (like `getUserAssignments`) just to flatten iterations, as this violates encapsulation and risks regressions. Eager computation for non-rendered rows causes performance regressions; instead, compute per-item stats lazily/on-demand for the currently paginated rows while using memoized O(1) maps for raw data lookups. Additionally, when optimizing global aggregate statistics in React, wrap the existing O(N*M) aggregation logic inside a `React.useMemo` block to prevent recalculation on every render while strictly preserving encapsulation.
**Action:** Optimize around context helpers by building frequency/lookup maps for raw arrays (e.g., `certificates`) and use those alongside existing helpers. Wrap expensive global aggregations inside `React.useMemo` to preserve encapsulation.
