## 2023-11-20 - Memoizing derived collections using Maps for O(1) lookups
**Learning:** In React list views like `AssignmentManagement.tsx`, merging two flat arrays (e.g. `users` and `courses` into `assignments`) via nested `.find()` iterations creates O(N*M) bottlenecks during derived data calculation, frequently triggered on search state changes. Bypassing context helpers and constructing `Map` instances first (`userMap`, `courseMap`) turns the lookup into O(1), optimizing the overall complexity to O(N+M).
**Action:** When deriving data inside a list render or hook that requires joining multiple arrays, aggressively wrap the source arrays into `useMemo`-backed `Map` structures before `.map()` mapping over the target collection, ensuring lookups are O(1) and the entire derived block is memoized.
