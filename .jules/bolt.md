## 2024-10-19 - O(1) frequency map and memoization for global admin tables
**Learning:** When calculating global aggregate statistics (like \`totalCompleted\`, \`employeeStats\`) on large tables (e.g. \`EmployeeManagement.tsx\`), calling a context helper method (like \`getUserAssignments\`) that iterates over full arrays for each rendered row results in an O(N*M) continuous recalculation trap on every render.
**Action:** Instead of mapping over filtered arrays for each item individually, create an upfront frequency map of the aggregate table directly via a single \`forEach\` or \`reduce\` pass on the primary data arrays. Memoize both the derived map and the consolidated global statistics block via \`useMemo\` to reduce computational complexity back to O(N+M) and preserve component performance on frequent re-renders.
