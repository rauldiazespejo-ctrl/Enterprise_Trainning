## 2024-05-15 - React Component Render Optimization
**Learning:** In lists or admin panels with many items, computing derived stats or filtered lists inside the main render function can cause significant performance overhead because those calculations rerun on every render, even for unrelated state updates (like typing in a search box). In particular, when functions execute filtering logic (O(N)) for each of M items during rendering, time complexity grows to O(N*M).
**Action:** Use `useMemo` in React components to cache expensive calculations such as aggregations, filtering, or array lookups, and ensure derived arrays used as dependencies are also memoized. Consolidate nested `find` and `filter` loops inside `map` into a single pass or use Maps for O(1) lookups to avoid O(N*M) performance drops during rendering.
