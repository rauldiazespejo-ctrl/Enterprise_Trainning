## 2024-05-15 - React Context Methods inside Loops
**Learning:** Using React context helper methods (like `getUserAssignments`) that internally filter an array (`assignments.filter`) inside a component loop or mapped list creates an O(N*M) nested loop pattern. This causes severe rendering performance issues since the derived aggregates are recalculated continuously and waste CPU cycles.
**Action:** When computing global aggregate statistics or list statistics, consolidate the calculations into a single pass using `.reduce()` or frequency maps to achieve O(N+M) complexity. Memoize these derived maps using `useMemo` so they are only recalculated when the underlying raw data (e.g. `assignments` or `certificates`) changes. Ensure locally derived arrays (like `employees = users.filter(...)`) used as dependencies are also memoized to prevent breaking the cache.
