## 2024-05-24 - Avoiding abstraction leaks when optimizing React component global statistics
**Learning:** When optimizing global aggregate statistics loops (like `totalCompleted` across all employees) in React components, do not bypass existing context helper functions (e.g., `getUserAssignments`) and access raw global arrays directly inside the loop just to "flatten" iterations. Doing so causes abstraction leaks and tight coupling to internal data structures that may change.
**Action:** Always preserve the use of existing context helpers when refactoring loops into O(1) maps or single `.reduce` passes. Wrap the optimized logic inside a `React.useMemo` block to get the performance benefits (avoiding recalculation on every render) while strictly maintaining component encapsulation.
