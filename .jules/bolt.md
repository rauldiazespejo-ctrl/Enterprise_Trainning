## 2024-05-21 - React useMemo Context Dependency Re-evaluation Anti-Pattern
**Learning:** Using locally derived arrays (like `const employees = users.filter(...)` inside the component body) as dependencies in a `useMemo` block completely negates the memoization. The inline filter creates a new array reference on every render, causing the `useMemo` hook to re-evaluate continuously, failing to cache the expensive O(N+M) Map calculation.
**Action:** When creating derived mappings with `useMemo`, either the source arrays themselves must be memoized first (`const employees = useMemo(() => users.filter(...), [users])`), or the `useMemo` block must depend directly on the upstream stabilized context arrays (`[users, assignments, certificates]`) to ensure the cache survives across renders.
