## 2024-05-24 - Context Helper Functions in useMemo Loops
**Learning:** When attempting to optimize repeated O(N) helper function calls (like `getUserAssignments(id)`) inside a loop into a single `useMemo` block, it is essential to retain the encapsulation of those helpers inside the `useMemo` dependency array rather than trying to manually re-implement their logic by looping over raw state arrays directly. Direct iteration of implicit raw arrays inside a component can cause `ReferenceError` crashes if the arrays are not actually declared or accessible in the component's lexical scope.
**Action:** When constructing an O(1) Map for nested calculations, use the existing helper function inside the `forEach` loop and add the helper function to the `useMemo` dependency array, rather than breaking encapsulation.
