## 2024-05-18 - Replacing O(N^2) Array operations with Map lookups in React Components\n**Learning:** When enriching arrays of data (e.g. `assignments.map`) with data from other arrays (e.g. `users.find`, `courses.find`), doing this directly inside the mapping function creates an O(N*M) or O(N^2) operation, causing significant performance bottlenecks during render loops.\n**Action:** Always pre-compute Map objects for O(1) lookups before the map iteration, and wrap the entire derived calculation in `useMemo` to prevent recalculation on every render.
