## 2024-05-18 - Avoid array methods inside loop maps without memoizing results
**Learning:** Calling `Array.prototype.filter` multiple times inside a `.map` for UI rendering creates an O(N*M) bottleneck. While `useMemo` can fix basic derived state, replacing frequent `filter` logic with a single-pass `Map` building reduces complexity to O(N+M).
**Action:** When performing aggregate statistics counting across related data (like fetching certificate counts per user), construct an O(1) Lookup Map via `useMemo` instead of calculating it eagerly via `.filter` on render. Also, when flattening nested array operations for performance, directly leverage existing context arrays (like `assignments`) in a single pass instead of re-wrapping iterative `getUserAssignments` helper functions if the original data is available locally.
