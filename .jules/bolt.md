## 2024-05-18 - Convert O(N*M) lookups to O(1) Maps in React loops
**Learning:** In list/management React components (like admin panels), calculating derived stats using helper functions (like `getUserAssignments`) inside `.map()` or `.reduce()` iterations causes O(N*M) recalculations. This triggers expensive re-renders on frequent state updates (like search input changes).
**Action:** Consolidate arrays (e.g. assignments and certificates) into a `Map` within a single `useMemo` pass, mapping `userId` to their respective stats. Then, retrieve the values directly from the Map inside the render or further derived state loops to achieve O(1) lookups and significantly improve time complexity (from O(N*M) to O(N+M)). Always define a `defaultStats` object statically outside the component to prevent referential equality breaks when returning fallbacks.
