## 2024-10-26 - O(N*M) Anti-Pattern with Context Helpers in Loops
**Learning:** Using context helper functions (like `getUserAssignments`) inside a loop or `.map()` function during a React component render can create massive performance bottlenecks (O(N*M)). Every iteration calls the helper, which filters a potentially large global array. Furthermore, computing multiple aggregate global stats from array derivatives using individual `.reduce()` and `.filter()` operations can lead to multiple O(N) passes that unnecessarily recalculate on every render.
**Action:** When needing aggregate data across items, build a memoized O(1) frequency or lookup map (e.g., `employeeStatsMap`) using `React.useMemo` to pre-calculate all needed statistics in a single O(N) pass. When deriving multiple global aggregates, compute them simultaneously in one unified loop wrapped in `useMemo`, ensuring all locally derived array dependencies (like the filtered `employees` list) are also memoized to prevent constant cache invalidation.
