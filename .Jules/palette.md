## 2024-10-18 - Improved Pagination Accessibility
**Learning:** Standard pagination controls often rely solely on visual cues (like colors for the active page or ellipses for skipped pages) which are inaccessible to screen readers. Relying on generic `div` elements omits structural context, and assistive technologies might announce decorative structural elements (like an ellipsis or arrow icons) confusingly.
**Action:** When building or maintaining pagination components, always wrap the controls in a semantic `<nav>` element with a descriptive `aria-label` (e.g., `aria-label="Navegación de páginas"`). Ensure the currently active page number button includes the `aria-current="page"` attribute, and provide individual `aria-label`s for each page number. Additionally, explicitly hide purely visual or structural elements (like ellipsis `<span>`s or navigational icons) by applying the `aria-hidden="true"` attribute.
