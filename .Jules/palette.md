## 2024-10-11 - Adding Semantic Structure and Touch Targets to Pagination Components
**Learning:** React generic component wrappers often neglect strict semantic boundaries (like using `<nav>` for pagination) and active states (`aria-current="page"`) out-of-the-box, significantly hindering screen reader users trying to navigate long lists. Additionally, dynamic ellipsis (`...`) elements can be incorrectly announced as interactive content if not properly hidden via `aria-hidden="true"`. Finally, pagination controls inherently suffer on mobile unless strict touch targets (like `.tap-target-min`) are enforced, especially for purely decorative or adjacent icon buttons.
**Action:** When implementing pagination, always wrap the controls in a `<nav aria-label="...">`, strictly assign `aria-current="page"` to the active page button, use `aria-hidden="true"` on non-interactive structural elements like ellipsis, and verify that mobile touch targets enforce minimum sizes on all adjacent controls.
