## 2024-10-24 - Semantic Pagination Landmarks and Touch Targets
**Learning:** React reusable pagination components often use `div` wrappers, which lack semantic meaning for screen readers. Using `<nav aria-label="...">` explicitly defines a navigation landmark. Also, dynamically mapping page numbers without `aria-current="page"` and applying custom interactive styles (`.focus-ring`, `.tap-target-min`) is crucial for keyboard and mobile accessibility, yet easily overlooked during generic component extraction.
**Action:** Always wrap pagination controls in a `<nav>` element with a descriptive `aria-label`. Apply `aria-current="page"` to the active page button and `aria-hidden="true"` to decorative elements like an ellipsis. Furthermore, consistently utilize the project's custom utility classes (`.focus-ring` and `.tap-target-min`) on interactive components rather than solely relying on generic browser states to ensure unified focus styles and adequate touch targets across devices.
