## 2024-05-15 - Pagination Accessibility and Interaction Patterns
**Learning:** Pagination components require significant semantic and interaction context. Structural elements like the wrapper must use a semantic `<nav>` tag with an `aria-label`. Individual page buttons must denote the current active page with `aria-current="page"` and explain their numerical purpose with `aria-label`. Decorative elements like `...` spans can confuse screen readers and must have `aria-hidden="true"`. To meet mobile tap-target accessibility standards, all interactive page controls need minimum size constraints (like `.tap-target-min`).
**Action:** When building pagination components, always wrap the controls in `<nav aria-label="...">`, apply `aria-current="page"` and individual `aria-labels` to numbered buttons, hide ellipsis elements with `aria-hidden="true"`, and apply `.tap-target-min` and `.focus-ring` classes for touch and keyboard usability.
