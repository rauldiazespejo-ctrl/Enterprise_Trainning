## 2024-03-28 - Accessible Pagination Components
**Learning:** When building pagination components, wrapping them in a standard `div` fails to provide context to screen readers. Standard page numbers also lack context without specific `aria-label`s, and the active page needs `aria-current="page"` to indicate its state. Additionally, structural/visual elements like ellipses or navigational icons can cause confusing screen reader announcements if not hidden.
**Action:** Always wrap pagination controls in a semantic `<nav>` element with a descriptive `aria-label` (e.g., `aria-label="Navegación de páginas"`). Provide individual `aria-label`s for each page number button, use `aria-current="page"` for the active page, and hide decorative elements (like `<span>...</span>` and Chevron icons) using `aria-hidden="true"`.
